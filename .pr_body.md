## Summary

Implements server-side order creation, Midtrans Snap checkout, database persistence, and retry/idempotency state handling in accordance with PRD 5.4, 7.1, 10, closing #36.

### Key Changes
1. **Server-Enforced Price Configuration (PRD 5.4):**
   - Strictly enforces single one-time price of **Rp 199.000** (`MVP_WEDDING_PRICE_IDR`) in `createCheckoutOrderAction`. Price is never accepted or read from client parameters.
   - Guarded against duplicate purchasing on already-licensed workspaces (`isPaid: true` and `status === 'active'`).
   - Sandbox demo workspace protection (`weddingId === 'demo'`).
2. **Order Number Generation & Persistence:**
   - Collision-resistant, readable order numbering format: `PATEMON-<SHORT_ID>-<TIMESTAMP_BASE36>-<RANDOM>`.
   - Persists checkout transactions into Supabase `checkout_orders` table with status `pending`, `snap_token`, `snap_redirect_url`, and records audit trails in `activity_logs` (`entity_type: checkout_order`).
3. **Idempotency & Retry Window Handling:**
   - If a user triggers checkout again while an existing order is in `pending` status within 45 minutes, reuses the existing `snap_token` and `order_number` to prevent duplicate pending charges.
   - Provides `cancelPendingOrderAction` to allow canceling an abandoned pending order so user can restart fresh.
4. **Midtrans Snap Client & Fallbacks:**
   - Built server-side Snap transaction client in `src/features/payments/midtrans.ts` using native fetch and HTTP Basic Auth.
   - `server-only` isolation ensures `MIDTRANS_SERVER_KEY` is never bundled client-side.
   - Automated mock/simulation mode for tests and staging when live keys are unconfigured.
   - Dynamic Snap JS script loading in `UpgradePromptModal` with complete lifecycle handling (`onSuccess`, `onPending`, `onError`, `onClose`), plus direct redirect fallback for popup-blockers.
5. **Settings UI Enhancements (`LicenseStatusCard`):**
   - Displays active Pending Order banner with order number, amount, "Lanjutkan Pembayaran", manual link, and "Batalkan Pesanan".
   - Displays transaction history table with status badges (`Berhasil`, `Menunggu`, `Dibatalkan`, `Kedaluwarsa`).
6. **Automated Testing & Quality Verification:**
   - Added 14 unit and integration tests in `tests/midtrans-snap-checkout.test.ts`.
   - All 18 test suites and 198 tests pass. Zero TypeScript errors, zero ESLint warnings, 100% Prettier formatted, and successful Next.js production build (`pnpm build`).
   - Documented in `docs/MIDTRANS-SNAP-CHECKOUT-GUIDE.md`.

Closes #36
